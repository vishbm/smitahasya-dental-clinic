SMITAHASYA DENTAL CLINIC - PREMIUM DEMO WEBSITE
================================================

1. PUT IT ONLINE (free)
   Open app.netlify.com/drop and drag this whole folder onto the page.
   You get a public link like https://something.netlify.app to send to dentists.

2. MAKE IT A REAL CLINIC'S SITE
   - app.js, top section CONFIG: set the WhatsApp number (digits with 91, e.g. 919876543210),
     the phone number, the map search text and the opening hours.
   - index.html: replace the clinic name, doctors, address, counters and reviews.
     Use only the clinic's real Google reviews, with reviewer names.

3. PHOTOS
   The img/ folder holds AI-generated demo photos. For a real clinic, replace each file
   with the clinic's own photo using the SAME file name and shape:
     img/hero.jpg      (1000 x 1200, portrait)
     img/about-1.jpg   (800 x 1000, portrait)
     img/about-2.jpg   (600 x 600, square)
     img/team-1.jpg, img/team-2.jpg, img/team-3.jpg   (800 x 600, landscape)
     img/tech.jpg, img/kids.jpg, img/hygiene.jpg       (1000 x 750, landscape)
     img/cta-bg.jpg    (1600 x 900, wide)
   Keep each file under about 200 KB so the site loads fast on mobile data.
   Never present AI-generated doctors as a real clinic's team.
   For a real clinic, use the clinic's own photos with the doctor's permission.
   For the demo, you can generate photos with Gemini or Google Flow using the prompts below.
   Do not show patient faces or before/after photos without written consent.
